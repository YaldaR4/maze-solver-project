Interactive Visualization – Maze Solver

After completing my final project, I wanted to explore the algorithms in a more visual and interactive way. For this reason, I created an additional implementation using HTML and JavaScript.
This visualization allows the user to run BFS, DFS, and A* directly in the browser and observe how each algorithm explores the maze step by step. It shows visited nodes and the final path, which makes it easier to understand the differences between the algorithms.

Live Visualization:
https://YaldaR4.github.io/maze-solver-project/

To run locally, download the repository and open:
index.html

This was an extension of my project to better understand the behavior of the algorithms visually.
